# BLACKBOXAI

BLACKBOXAI is an AI-powered application built with Next.js, React, and various UI components.

## Getting Started

1. Clone the repository:
   ```
   git clone https://github.com/raditself/q.git
   cd q
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Run the development server:
   ```
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

## Features

- AI-powered chat interface
- Code editor
- Terminal emulator

## Technologies Used

- Next.js
- React
- TypeScript
- Radix UI
- Tailwind CSS
